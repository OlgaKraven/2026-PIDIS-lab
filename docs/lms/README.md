# Настройка заданий в LMS

Для каждой лабораторной создайте элемент «Задание» и настройте приём одного файла формата DOCX.

## Единые параметры

- тип ответа: отправка файла;
- максимальное количество файлов: 1;
- допустимый тип: `.docx`;
- имя файла: `ID_Фамилия_Группа.docx`;
- оценивание: 10 баллов по рубрике из `teacher/`;
- описание: ссылка на страницу лабораторной, лекцию и DOCX-шаблон;
- не использовать число страниц как основной критерий качества.

## Текст для блока сдачи

«Прикрепите один DOCX-файл. Вставьте таблицы, схемы, макеты и скриншоты непосредственно в отчёт. Перед отправкой выполните чек-лист самопроверки. Дополнительные файлы не требуются».

Конкретная ссылка на курс зависит от настройки LMS и не хранится в репозитории; стенд ведёт на защищённую главную страницу Synergy LMS.
