# Сохранение и переработка курса

Исходный коммит: d13125b4f78abfec3f336be81452c931af48069c. Все исходные файлы перед изменением сохранены локально в private/original. Названия, номера, семестры, разделы и баллы сравниваются автоматически.

Перенесена фактическая оболочка лабораторного шаблона: каталог, выбор варианта, фильтры, настройки, страница, автономный экспорт. Адаптированы составные маршруты, соседние работы, изоляция настройки варианта и мобильная сетка. Добавлен единый resolver фактических вариантных данных для страницы и ZIP.

Старые общие шаги дополнены предметными действиями, доказательствами и проверками. Word-формы повторно собраны по сохранённому титульному образцу, каждая имеет собственные рабочие разделы. Реестры и ключи не импортируются в клиент.

Исходные текстовые кейсы сохранены. Проект не содержал отдельных исполняемых стендов; работа не объявляется проверкой отсутствующего серверного приложения. Варианты PV сохраняют собственную предметную область. Условия A–AD из текстовых кейсов не подменяют эту структуру.

Связь с экзаменационными задачами используется как контекст подготовки. Учебный API /api/work-notes и его расширенные поля сохранены; они не объявляются буквальной копией экзаменационного контракта. Различия поясняются внутри задания.
