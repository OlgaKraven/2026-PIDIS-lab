# Методическая карточка · C3-S5-LR11

> Материал преподавателя. Не публиковать как готовый ответ на студенческом стенде и не включать в шаблон отчёта.

## Цель и навык

- Цель: Преобразовать найденные правила в однозначные проверяемые записи.
- Наблюдаемый навык: Формулировать правило через условие, обязанность/запрет и наблюдаемый результат.
- Связь с лекцией: Бизнес-правила, Качество формулировок.

## Ожидаемый результат

Восемь правил с ID, источниками, исключениями и критериями проверки.

## Возможное правильное решение

Правила резервирования и прав доступа формулируются полностью; исключение для повреждённой маркировки остаётся открытым вопросом.

## Допустимые варианты

Допустимы эквивалентные формы записи, если сохраняются условие, обязательность и наблюдаемый результат.

| Поле | Пример ответа |

| Обоснование | Решение связано с подтверждённым фактом и не добавляет неизвестные условия. |
| Критерий проверки | Для каждой записи можно построить минимум один позитивный и один негативный пример. |
| Доказательство | Заполненный артефакт и ссылка на строку исходных данных. |

## Типичные ошибки

- Добавлять исключение «по решению администратора», которого нет в исходных данных.
- Подмена исходного факта предположением без маркировки.
- Отсутствие связи между решением и способом проверки.
- Визуальный результат невозможно прочитать без устного объяснения.

## Подсказка для слабых студентов

Подчеркните модальные слова «должен», «нельзя», «только» и проверьте, кто, когда и над чем выполняет правило.

Дайте студенту начать с одной строки «факт — источник — решение — проверка», затем предложите повторить структуру для остальных записей.
