# Методическая карточка · C3-S5-LR08

> Материал преподавателя. Не публиковать как готовый ответ на студенческом стенде и не включать в шаблон отчёта.

## Цель и навык

- Цель: Устранить разночтения терминов между участниками проекта.
- Наблюдаемый навык: Создавать управляемый глоссарий с допустимыми синонимами и запретами.
- Связь с лекцией: Глоссарий проекта.

## Ожидаемый результат

Не менее 12 терминов с определениями через наблюдаемые признаки и решениями по синонимам.

## Возможное правильное решение

«Заявка клиента» выбирается основным термином, «заказ» фиксируется как разговорный синоним; «пользователь» и «клиент» разводятся.

## Допустимые варианты

Основной термин может быть иным, если он согласован с документами и используется последовательно.

## Типичные ошибки

- Определять термин через то же слово или через название экранной формы.
- Подмена исходного факта предположением без маркировки.
- Отсутствие связи между решением и способом проверки.
- Визуальный результат невозможно прочитать без устного объяснения.

## Подсказка для слабых студентов

Сгруппируйте слова по объектам, событиям, ролям и состояниям; затем ищите пересечения.

Дайте студенту начать с одной строки «факт — источник — решение — проверка», затем предложите повторить структуру для остальных записей.
