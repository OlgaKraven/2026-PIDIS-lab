# Методическая карточка · C3-S6-LR06

> Материал преподавателя. Не публиковать как готовый ответ на студенческом стенде и не включать в шаблон отчёта.

## Цель и навык

- Цель: Связать рабочие обязанности с минимально необходимыми правами.
- Наблюдаемый навык: Строить матрицу ролей, объектов и операций и выявлять конфликт полномочий.
- Связь с лекцией: Ролевая модель доступа.

## Ожидаемый результат

Матрица по 10–14 операциям, легенда прав и два сценария проверки.

## Возможное правильное решение

Администратор управляет учётными записями, но не подтверждает маркировку; отмена после отбора остаётся у начальника смены.

## Допустимые варианты

Совмещение ролей допустимо только как отдельное решение с анализом конфликта.

## Типичные ошибки

- Выдавать администратору все бизнес-права только из-за технической роли.
- Подмена исходного факта предположением без маркировки.
- Отсутствие связи между решением и способом проверки.
- Визуальный результат невозможно прочитать без устного объяснения.

## Подсказка для слабых студентов

Разделите операции на просмотр, создание, изменение, подтверждение, отмену и администрирование.

Дайте студенту начать с одной строки «факт — источник — решение — проверка», затем предложите повторить структуру для остальных записей.
