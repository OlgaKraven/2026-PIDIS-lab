# Методическая карточка · C3-S6-LR03

> Материал преподавателя. Не публиковать как готовый ответ на студенческом стенде и не включать в шаблон отчёта.

## Цель и навык

- Цель: Определить состав и поведение полей формы на основе требований и правил.
- Наблюдаемый навык: Специфицировать поля, источники значений, обязательность и зависимость между полями.
- Связь с лекцией: Формы, валидация и состояния.

## Ожидаемый результат

Полная спецификация 8–12 полей с источниками и зависимостями.

## Возможное правильное решение

Номер задания, товар и резерв доступны только для чтения; фактическое количество вводится; причина становится обязательной при расхождении.

## Допустимые варианты

Другая доступность допустима при связи с полномочиями роли и бизнес-правилом.

## Типичные ошибки

- Делать все отображаемые значения редактируемыми.
- Подмена исходного факта предположением без маркировки.
- Отсутствие связи между решением и способом проверки.
- Визуальный результат невозможно прочитать без устного объяснения.

## Подсказка для слабых студентов

Для каждого поля поставьте метку: «из системы», «от пользователя», «вычисляется».

Дайте студенту начать с одной строки «факт — источник — решение — проверка», затем предложите повторить структуру для остальных записей.
