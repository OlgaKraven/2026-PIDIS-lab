# Методическая карточка · C3-S5-LR05

> Материал преподавателя. Не публиковать как готовый ответ на студенческом стенде и не включать в шаблон отчёта.

## Цель и навык

- Цель: Стабилизировать реестр и построить первую трассу от источника к проверке.
- Наблюдаемый навык: Назначать устойчивые ID, управлять источниками и находить разрывы трассировки.
- Связь с лекцией: Допущения и трассируемость, Карта артефактов.

## Ожидаемый результат

Соглашение об ID, обновлённый реестр и не менее 8 трасс с отмеченными разрывами.

## Возможное правильное решение

Устойчивый ID отражает тип и порядковый номер, а версия — изменение текста; удалённый ID не переиспользуется.

## Допустимые варианты

Допустимы иные схемы кодирования, если они уникальны, стабильны и документированы.

## Пример заполненного артефакта

| Поле | Пример ответа |

| ID | C3-S5-LR05-EX-01 |

| Источник факта | Учебный пакет заказчика |

| Обоснование | Решение связано с подтверждённым фактом и не добавляет неизвестные условия. |
| Критерий проверки | По любой строке можно перейти к источнику, решению и проверке без поиска по похожему тексту. |
| Доказательство | Заполненный артефакт и ссылка на строку исходных данных. |

## Типичные ошибки

- Менять ID при каждой редакции формулировки.
- Подмена исходного факта предположением без маркировки.
- Отсутствие связи между решением и способом проверки.
- Визуальный результат невозможно прочитать без устного объяснения.

## Подсказка для слабых студентов

Проверьте три вопроса: ID уникален? источник точен? способ проверки уже можно назвать?

Дайте студенту начать с одной строки «факт — источник — решение — проверка», затем предложите повторить структуру для остальных записей.

## Вопросы для обсуждения

- Что опаснее: требование без источника или решение без требования?
- Как изменится решение при смене ограничения индивидуального варианта?
- Как доказать заказчику, что артефакт готов к следующему этапу?
