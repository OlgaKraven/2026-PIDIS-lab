# Методическая карточка · C3-S5-LR16

> Материал преподавателя. Не публиковать как готовый ответ на студенческом стенде и не включать в шаблон отчёта.

## Цель и навык

- Цель: Найти пропуски и лишние решения в чужом комплекте материалов.
- Наблюдаемый навык: Проводить взаимную ревизию по доказательному чек-листу.
- Связь с лекцией: Ревизия модели.

## Ожидаемый результат

Заключение с 6–10 замечаниями, приоритетами и ссылками на доказательства.

## Возможное правильное решение

Блокирующими считаются непокрытое обязательное правило и отсутствие сущности, нужной нескольким требованиям; стилистические замечания ниже приоритетом.

## Допустимые варианты

Приоритеты допустимы разные, если объяснено влияние на следующий проектный артефакт.

## Типичные ошибки

- Исправлять чужой комплект без фиксации обнаруженного факта и риска.
- Подмена исходного факта предположением без маркировки.
- Отсутствие связи между решением и способом проверки.
- Визуальный результат невозможно прочитать без устного объяснения.

## Подсказка для слабых студентов

Сначала выпишите расхождения с источником, затем последствия; не начинайте с вкусовых формулировок.

Дайте студенту начать с одной строки «факт — источник — решение — проверка», затем предложите повторить структуру для остальных записей.
