# Методическая карточка · C3-S5-LR18

> Материал преподавателя. Не публиковать как готовый ответ на студенческом стенде и не включать в шаблон отчёта.

## Цель и навык

- Цель: Сравнить альтернативы по критериям, связанным с требованиями.
- Наблюдаемый навык: Назначать критерии и веса без подгонки результата под заранее выбранный вариант.
- Связь с лекцией: Матрица решений, Влияние нефункциональных требований.

## Ожидаемый результат

Матрица с нормированными весами, расчётом, проверкой чувствительности и кратким выводом.

## Возможное правильное решение

В базовом варианте сканирование выигрывает при высоком весе контроля ошибок; пакетная проверка становится лидером только при иной подтверждённой нагрузке.

## Допустимые варианты

Любой вариант может быть выбран, если матрица воспроизводима и чувствительность разобрана.

## Типичные ошибки

- Менять веса после получения нежелательного результата без нового факта.
- Подмена исходного факта предположением без маркировки.
- Отсутствие связи между решением и способом проверки.
- Визуальный результат невозможно прочитать без устного объяснения.

## Подсказка для слабых студентов

Сначала заполните критерии и веса, закройте их, затем оценивайте варианты.

Дайте студенту начать с одной строки «факт — источник — решение — проверка», затем предложите повторить структуру для остальных записей.
