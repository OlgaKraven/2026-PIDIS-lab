# Методическая карточка · C3-S5-LR13

> Материал преподавателя. Не публиковать как готовый ответ на студенческом стенде и не включать в шаблон отчёта.

## Цель и навык

- Цель: Проследить происхождение каждого атрибута из документов и решений.
- Наблюдаемый навык: Различать атрибуты заказчика, служебные и вычисляемые значения.
- Связь с лекцией: Атрибутный состав, Источники требований.

## Ожидаемый результат

Матрица для 4–6 сущностей, где каждый атрибут имеет происхождение или обоснование.

## Возможное правильное решение

Служебные статусы и дата создания добавляются как проектные решения; доступное количество отмечается вычисляемым.

## Допустимые варианты

Допустим иной служебный набор при доказанной потребности и отсутствии дублирования.

## Типичные ошибки

- Считать вычисляемое значение полем документа только потому, что оно выведено на экран.
- Подмена исходного факта предположением без маркировки.
- Отсутствие связи между решением и способом проверки.
- Визуальный результат невозможно прочитать без устного объяснения.

## Подсказка для слабых студентов

Отмечайте рядом с каждым полем: «документ», «решение» или «формула»; пустая категория — сигнал риска.

Дайте студенту начать с одной строки «факт — источник — решение — проверка», затем предложите повторить структуру для остальных записей.
