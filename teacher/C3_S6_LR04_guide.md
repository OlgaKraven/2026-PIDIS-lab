# Методическая карточка · C3-S6-LR04

> Материал преподавателя. Не публиковать как готовый ответ на студенческом стенде и не включать в шаблон отчёта.

## Цель и навык

- Цель: Спроектировать предотвращение ошибок и понятную обратную связь.
- Наблюдаемый навык: Связывать правило валидации с моментом проверки, текстом сообщения и состоянием экрана.
- Связь с лекцией: Формы, валидация и состояния.

## Ожидаемый результат

Матрица минимум из 8 проверок и визуальная карта пяти состояний.

## Возможное правильное решение

Для превышения резерва сообщение показывает доступное количество и возвращает фокус в поле; сетевой сбой сохраняет введённые данные.

## Допустимые варианты

Формулировки могут отличаться, если они конкретны, доступны и не обвиняют пользователя.

## Типичные ошибки

- Использовать один текст «Что-то пошло не так» для разных причин.
- Подмена исходного факта предположением без маркировки.
- Отсутствие связи между решением и способом проверки.
- Визуальный результат невозможно прочитать без устного объяснения.

## Подсказка для слабых студентов

Прочитайте сообщение без экрана: понятно ли, какое действие доступно дальше?

Дайте студенту начать с одной строки «факт — источник — решение — проверка», затем предложите повторить структуру для остальных записей.
