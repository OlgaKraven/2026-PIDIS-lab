# Методическая карточка · C3-S5-LR15

> Материал преподавателя. Не публиковать как готовый ответ на студенческом стенде и не включать в шаблон отчёта.

## Цель и навык

- Цель: Выбрать способ хранения изменяемых значений с учётом прошлых документов.
- Наблюдаемый навык: Сравнивать варианты историчности и объяснять влияние решения на отчётность.
- Связь с лекцией: Историчность данных, Матрица решений.

## Ожидаемый результат

Решение минимум для двух изменяемых величин с проверкой на прошлом документе.

## Возможное правильное решение

Для тарифа обоснованы интервалы действия или снимок в отгрузке; для справочного названия может быть достаточно текущего значения.

## Допустимые варианты

Оба основных подхода допустимы при доказанном поведении прошлых документов.

## Типичные ошибки

- Выбирать самый сложный вариант «на всякий случай» без требования к истории.
- Подмена исходного факта предположением без маркировки.
- Отсутствие связи между решением и способом проверки.
- Визуальный результат невозможно прочитать без устного объяснения.

## Подсказка для слабых студентов

Нарисуйте две даты: дату прошлой операции и дату изменения значения — затем проверьте, что увидит пользователь.

Дайте студенту начать с одной строки «факт — источник — решение — проверка», затем предложите повторить структуру для остальных записей.
