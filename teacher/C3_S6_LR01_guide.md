# Методическая карточка · C3-S6-LR01

> Материал преподавателя. Не публиковать как готовый ответ на студенческом стенде и не включать в шаблон отчёта.

## Цель и навык

- Цель: Связать рабочие цели ролей со структурой разделов системы.
- Наблюдаемый навык: Строить сценарии и информационную архитектуру без копирования структуры данных.
- Связь с лекцией: Пользовательские цели, Информационная архитектура.

## Ожидаемый результат

Три сценария и дерево ИА с приоритетами, названиями разделов и связью с задачами.

## Возможное правильное решение

Для кладовщика основой становится очередь заданий и текущий отбор; контроль и администрирование вынесены в ролевые разделы.

## Допустимые варианты

Другая группировка допустима при коротком пути и понятных названиях для целевой роли.

## Типичные ошибки

- Строить меню из названий сущностей и показывать всем ролям одинаковую навигацию.
- Подмена исходного факта предположением без маркировки.
- Отсутствие связи между решением и способом проверки.
- Визуальный результат невозможно прочитать без устного объяснения.

## Подсказка для слабых студентов

Разложите карточки задач по группам и назовите каждую группу глаголом или понятной рабочей целью.

Дайте студенту начать с одной строки «факт — источник — решение — проверка», затем предложите повторить структуру для остальных записей.
