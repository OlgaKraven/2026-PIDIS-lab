# Методическая карточка · C3-S5-LR12

> Материал преподавателя. Не публиковать как готовый ответ на студенческом стенде и не включать в шаблон отчёта.

## Цель и навык

- Цель: Выбрать доказательство выполнения каждого правила.
- Наблюдаемый навык: Сопоставлять правило с проверкой данных, сценария, роли или документа.
- Связь с лекцией: Бизнес-правила.

## Ожидаемый результат

Для каждого правила выбран выполнимый способ проверки и указан ожидаемый результат.

## Возможное правильное решение

Ограничения количества проверяются граничными наборами данных; права — матрицей и сценариями; историчность — сравнением двух дат.

## Допустимые варианты

## Типичные ошибки

- Назначать всем правилам один универсальный способ проверки.
- Подмена исходного факта предположением без маркировки.
- Отсутствие связи между решением и способом проверки.
- Визуальный результат невозможно прочитать без устного объяснения.

## Подсказка для слабых студентов

Сначала определите, что должно быть видно проверяющему, затем выбирайте инструмент.

Дайте студенту начать с одной строки «факт — источник — решение — проверка», затем предложите повторить структуру для остальных записей.
