# Лабораторные работы по МДК.05.01

Проектирование и дизайн информационных систем. Обновление существующего курса на основе `2026-lab-shablone`, коммит `87c8f7a4c1c48cc49a2c3d1a8c0db18cef5f478b`.

Сохранены 20 названий и исходные номера: 8 работ в семестре 5, 7 в семестре 6, 5 в семестре 7. Баллы сохранены: **43 / 30 / 27**, всего 100. Сохранены 30 предметных вариантов PV01–PV30. Номера внутри семестров повторяются; маршруты используют исходные составные ID.

Каждая работа содержит локальные объяснения, отдельный пример, самостоятельные действия, проверку результата, критерии и собственную редактируемую форму Word. Ссылок и отсылок к лекциям в студенческой выдаче нет. Оценки продолжительности доступны только в локальном сопровождении преподавателя.

## Запуск и проверки

Node.js 24, npm. Зависимости зафиксированы в package-lock.json.

```sh
npm ci
npm run typecheck
npm run check:course
npm run build
node scripts/check-privacy.mjs
npm run preview -- --host 127.0.0.1 --port 4181
```

При запущенном preview `node scripts/browser-check.mjs` проверяет страницы, все 600 наборов и реальные ZIP. Адрес можно изменить переменной `SITE_URL`. `python scripts/check-archives.py` независимо сравнивает CSV, HTML и DOCX скачанных комплектов; нужны lxml и Python 3.

## Исходники и обновление материалов

- `authoring/original-labs.json` — исходные публичные реквизиты и предметные результаты.
- `authoring/original-variants.json` — сохранённые 30 предметных областей.
- `authoring/design.mjs` — теория, действия, примеры и композиция каждой формы.
- `authoring/datasets.mjs` — воспроизводимые рабочие данные без закрытых ключей.
- `npm run generate:course` — обновляет сайт, задания Markdown, реестры и сопровождение в игнорируемой папке private.
- `python scripts/generate-docx.py` — создаёт 20 DOCX из сохранённого образца и предметных структур; нужен python-docx. Обычная сборка сайта Word не создаёт.
- `scripts/render_reports.ps1` — экспорт через установленный Microsoft Word и растеризация Poppler. Пути окружения при переносе задаются в скрипте.
- `public/reports` — проверенные формы Word, используемые прямым скачиванием и всеми ZIP.

После изменения данных увеличивайте версию в генераторе, повторяйте проверки затронутых вариантов и архивов. После изменения формы повторяйте визуальную проверку и испытание заполнением. Исторические отчёты шаблона не являются проверкой этого курса.

## Существующие кейсы и границы

Исходные WMS «Маршрут» и Field Service «Выезд» сохранены в inputs. Это текстовые учебные кейсы: отдельных серверных приложений, контейнеров или исполняемых симуляторов в исходном репозитории нет. Сохранены проектные задачи по данным, ролям, входу и API; программирование API не добавлено. Выбранная предметная область PV определяет рабочие данные. Старые обозначения A–AD в кейсах являются ситуационными дополнениями, а не заменой предметных вариантов PV.

Сайт выдаёт материалы, но не принимает отчёты и не выставляет оценки. LMS сохранена из первоначального проекта. Студенческий архив включает автономный HTML со встроенным шрифтом, DOCX и CSV выбранного варианта. Настройки преподавателя позволяют скачать учебные материалы всех вариантов; закрытых решений в этих публичных ZIP нет.

## Сопровождение преподавателя

Закрытые ключи, исходный защищённый реестр, карта связи с прочитанными материалами, паспорта наборов, расчёты и журнал работы передаются отдельно в локальном комплекте private. Папка исключена из Git и сборки. Без `private/answer-model.mjs` генератор честно отмечает недоступность закрытых ключей; не создаёт фиктивных ответов. Старые опубликованные материалы остаются в истории Git: исключение из текущей версии не удаляет историю.

РПД не предоставлена; соответствие официальным часам не заявляется. Пилотное прохождение начинающими студентами не проводилось. Технические результаты и границы проверки — в `docs/QUALITY.md`.
