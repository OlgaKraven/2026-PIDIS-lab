# 2026-PIDIS-lab

Система лабораторных работ по МДК.05.01 «Проектирование и дизайн информационных систем» для специальности 09.02.07 «Информационные системы и программирование».

## Состав

- 20 самостоятельных лабораторных работ: 8 в 5 семестре, 7 в 6 семестре, 5 в 7 семестре;
- 100 баллов за три семестра, распределённых по сложности работ;
- сквозные учебные кейсы и исходные данные;
- отдельный редактируемый DOCX-шаблон для каждой работы;
- закрытый от студенческого сайта комплект методических карточек и рубрик преподавателя;
- адаптивный каталог с фильтрами, страницей каждой работы, ссылками на лекции, материалы, DOCX и LMS;
- автоматические проверки структуры, ссылок, сборки и доступности.

## Структура

- `content/` — студенческие задания;
- `inputs/` — учебные кейсы и документы;
- `reports/` — DOCX-шаблоны;
- `teacher/` — методические карточки и рубрики;
- `coverage-matrix.md` — покрытие тем действием, артефактом и критерием;
- `src/` — приложение информационного стенда;
- `scripts/` и `tests/` — генерация и проверки;
- `docs/lms/` — инструкция по настройке заданий LMS.

## Локальная проверка

```powershell
pnpm run lint
pnpm run typecheck
pnpm run spellcheck
pnpm run test
pnpm run build
pnpm run test:links
pnpm run test:smoke
```

## Публикация

Workflow `.github/workflows/pages.yml` собирает стенд и публикует `dist/` через GitHub Pages после отправки изменений в `main` или ручного запуска. Ожидаемый адрес: https://olgakraven.github.io/2026-PIDIS-lab/

Материалы преподавателя не копируются в `dist/` и не отображаются на публичном стенде.
