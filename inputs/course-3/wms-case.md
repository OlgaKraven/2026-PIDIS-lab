# Учебный сквозной кейс 3 курса: WMS «Маршрут»

> Все названия, роли, процессы и числа в этом файле являются данными учебной задачи и не описывают реальную организацию.

## Ситуация

Учебный распределительный центр «Маршрут» принимает товары партиями, размещает их по ячейкам, резервирует под заявки клиентов, формирует задания на отбор и подтверждает маркировку перед отгрузкой. Сейчас сотрудники используют таблицы и бумажные формы. Заказчик хочет единую информационную систему без потери обязательного контроля.

## Документы

| Документ | Ключевые поля | Наблюдение аналитика |
|---|---|---|
| Заявка клиента | номер, клиент, дата, адрес, позиция, количество, желаемая дата | приоритет обработки явно не задан |
| Карточка товара | артикул, наименование, единица, срок годности, признак маркировки | признак влияет на контроль перед отгрузкой |
| Остатки | артикул, ячейка, партия, срок годности, остаток, резерв | доступное количество вычисляется |
| Задание на отбор | номер, заявка, кладовщик, статус, начало, завершение | отмена после начала ограничена ролью |
| Журнал пользователей | логин, роль, статус, неуспешные попытки, дата блокировки | данные нужны сценарию входа |

## Подтверждённые правила учебной задачи

1. Фактически отобранное количество не превышает зарезервированное.
2. Товар с обязательной маркировкой нельзя передать в отгрузку без подтверждения контролёра.
3. После начала отбора отменить задание может только начальник смены.
4. Тариф клиента определяется на дату отгрузки; прошлые документы не должны пересчитываться после изменения тарифа.
5. После трёх последовательных неуспешных попыток входа учётная запись переходит в состояние `blocked`.
6. Снять блокировку может администратор после проверки пользователя; действие фиксируется в журнале.

## Индивидуальные варианты A–F

| Вариант | Роль фокуса | Ограничение | Противоречие |
|---|---|---|---|
| A | кладовщик | мобильный экран 390 px | скорость против обязательной проверки |
| B | контролёр | работа в перчатках | крупные цели против плотной таблицы |
| C | начальник смены | несколько зон хранения | единая очередь против локальных приоритетов |
| D | администратор | запрет бизнес-операций | помощь пользователю против минимальных прав |
| E | менеджер клиента | неполные адреса | быстрый ввод против качества данных |
| F | руководитель | агрегированные показатели | актуальность против сохранения истории |
