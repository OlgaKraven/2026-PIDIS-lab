# Учебный сквозной кейс 3 курса: WMS «Маршрут»

> Все названия, роли, процессы и числа в этом файле являются данными учебной задачи и не описывают реальную организацию.

## Ситуация

Учебный распределительный центр «Маршрут» принимает товары партиями, размещает их по ячейкам, резервирует под заявки клиентов, формирует задания на отбор и подтверждает маркировку перед отгрузкой. Сейчас сотрудники используют таблицы и бумажные формы. Заказчик хочет единую информационную систему без потери обязательного контроля.

## Документы

| Документ | Ключевые поля | Наблюдение аналитика |
|---|---|---|
| Заявка клиента | номер, клиент, дата, адрес, позиция, количество, желаемая дата | приоритет обработки явно не задан |
| Карточка товара | артикул, наименование, единица, срок годности, признак маркировки | признак влияет на контроль перед отгрузкой |
| Остатки | артикул, ячейка, партия, срок годности, остаток, резерв | доступное количество вычисляется |
| Задание на отбор | номер, заявка, кладовщик, статус, начало, завершение | отмена после начала ограничена ролью |
| Журнал пользователей | логин, роль, статус, неуспешные попытки, дата блокировки | данные нужны сценарию входа |

## Подтверждённые правила учебной задачи

1. Фактически отобранное количество не превышает зарезервированное.
2. Товар с обязательной маркировкой нельзя передать в отгрузку без подтверждения контролёра.
3. После начала отбора отменить задание может только начальник смены.
4. Тариф клиента определяется на дату отгрузки; прошлые документы не должны пересчитываться после изменения тарифа.
5. После трёх последовательных неуспешных попыток входа учётная запись переходит в состояние `blocked`.
6. Снять блокировку может администратор после проверки пользователя; действие фиксируется в журнале.

## Индивидуальные ситуационные варианты A–AD

Преподаватель назначает один вариант на студента. Подтверждённые правила кейса сохраняются: вариант добавляет особую ситуацию, но не отменяет базовые ограничения. Если сведений для решения недостаточно, студент должен зафиксировать допущение или вопрос заказчику, а не придумывать факт.

| Вариант | Роль фокуса | Ситуация и ограничение | Проектное противоречие или решение |
|---|---|---|---|
| A | кладовщик | основной сценарий выполняется на мобильном экране шириной 390 px | скорость отбора против обязательной проверки маркировки |
| B | контролёр | сотрудник работает в перчатках и не может точно нажимать мелкие элементы | крупные цели управления против плотной таблицы позиций |
| C | начальник смены | склад разделён на три зоны с разной текущей загрузкой | единая очередь заданий против локальных приоритетов зон |
| D | администратор | администратору запрещено выполнять складские бизнес-операции | помощь пользователю против принципа минимальных прав |
| E | менеджер клиента | часть заявок поступает с неполным адресом доставки | быстрый ввод заявки против качества и корректности адреса |
| F | руководитель | нужны агрегированные показатели и возможность разобрать конкретную задержку | актуальная сводка против сохранения исторического контекста |
| G | приёмщик | этикетка поставщика содержит артикул, которого нет в справочнике | быстрое принятие партии против подтверждения идентичности товара |
| H | оператор размещения | одна партия указана в коробках, а остатки учитываются в штуках | удобный пересчёт единиц против риска потерять исходное количество |
| I | новый кладовщик | сотруднику доступен только сканер с небольшим экраном и нет бумажной инструкции | короткий маршрут действий против необходимости объяснить ошибку |
| J | удалённый контролёр | контроль маркировки выполняется по фотографии | достаточность доказательства против лишних данных на изображении |
| K | координатор отгрузки | две срочные заявки претендуют на один доступный остаток | приоритет клиента против ранее созданного резерва |
| L | специалист по инвентаризации | после пересчёта обнаружен отрицательный доступный остаток | быстрое исправление числа против сохранения причины расхождения |
| M | начальник смены | в одной зоне склада нестабильно работает сеть | продолжение отбора без связи против актуальности общего статуса |
| N | менеджер клиента | адрес доставки изменён после резервирования и формирования задания | гибкость для клиента против устойчивости маршрута и документов |
| O | кладовщик | ближайшая по сроку партия временно недоступна из-за повреждённой упаковки | соблюдение FEFO против допустимого исключения из правила |
| P | специалист по возвратам | клиент вернул товар с целой маркировкой, но без подтверждённой причины возврата | повторное использование товара против контроля его состояния |
| Q | начальник смены | две смены одновременно работают с одной крупной заявкой | параллельная работа против конфликтующих изменений статуса |
| R | администратор | заболевшего начальника смены временно заменяет кладовщик | непрерывность работы против выдачи избыточных постоянных прав |
| S | специалист поддержки | пользователь просит срочно снять блокировку по телефону | скорость восстановления доступа против проверки личности |
| T | кладовщик | штрихкод ячейки повреждён, разрешён ручной ввод кода | завершение операции против риска ошибки идентификации ячейки |
| U | специалист качества | партия помещена в карантин уже после создания резерва | выполнение заявки против запрета использовать спорную партию |
| V | планировщик | для заявки хватает товара только при частичной отгрузке из двух зон | целостность одной заявки против разрешения частичного исполнения |
| W | водитель-экспедитор | передача груза подтверждается на мобильном устройстве без стабильной сети | доказательство передачи против возможности работать офлайн |
| X | специалист интеграции | внешний сервис маркировки возвращает статус с задержкой | доступность операции против подтверждённой согласованности статусов |
| Y | менеджер клиента | повторное письмо клиента похоже на уже зарегистрированную заявку | не потерять обращение против появления дубликата |
| Z | аудитор | тариф клиента изменился, а проверяется отгрузка прошлого месяца | текущий справочник против значения, действовавшего на дату операции |
| AA | комплектовщик | одна позиция заявки хранится в двух партиях с разными сроками годности | минимальное число подходов против обоснованного выбора партии |
| AB | контролёр | в задании десять маркированных позиций, одна проверка завершилась ошибкой | повтор всей проверки против точечного исправления с доказательством |
| AC | руководитель | сотрудник переводится в другую зону в середине смены | оперативное перераспределение против корректной истории ответственности |
| AD | оператор отгрузки | клиент отменяет заявку после фактического отбора, но до передачи водителю | возврат товара в доступный остаток против сохранения следов операции |
