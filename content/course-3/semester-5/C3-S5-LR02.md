# C3-S5-LR02 · Реестр требований по документам заказчика

Семестр 5. Максимум 4 баллов.

Составить единый реестр требований по документам заказчика.

## Атомарное требование

Одна запись описывает одно проверяемое обязательство. Разделяйте хранение данных, действие системы, ограничение качества и бизнес-правило. Сначала укажите цитату или ID источника, затем собственную формулировку. Поле в документе подтверждает наличие информации, но не доказывает автоматическое действие системы. Например, дата не означает приоритет без отдельного правила.

## Статус знания

Подтверждённое требование имеет явное основание. Предположение фиксирует возможное объяснение, вопрос — недостающий факт, конфликт — несовместимые сведения. Не назначайте числовой порог вместо неопределённого слова «быстро». Запишите, какой показатель и условия измерения нужно согласовать. Несогласованный черновик не получает статус утверждённого правила.

## Действия

1. Извлеките требования. Составьте 16–20 атомарных записей с ID и источником. Проверка: Ни одна запись не объединяет независимые обязанности.
2. Классифицируйте записи. Отметьте функциональные требования, данные, ограничения качества и бизнес-правила. Проверка: Класс объяснён назначением записи.
3. Разрешите неопределённость. Укажите противоречащие ID, вопрос и участника из предыдущей карты. Проверка: Вопрос направлен тому, кто владеет нужным сведением.

Выдаваемый архив содержит условия выбранного варианта, все таблицы CSV и собственную форму DOCX.
